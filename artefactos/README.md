# Analysis artefacts

This folder contains the non-code business-process artefacts retained from the academic project:

- `BMC.pdf` — Business Model Canvas;
- `MapaProcessos.pdf` — process map;
- `SIPOC-Venda.pdf` — SIPOC analysis for machine sales;
- `SIPOC-Reparacao.pdf` — SIPOC analysis for machine repair;
- `MachineSale.pdf` — rendered machine-sale BPMN model;
- `ReparacaoMaquinas.pdf` — rendered machine-repair BPMN model.

The original group report and presentation are intentionally not included in the public portfolio version because they contain personal information about other participants.
